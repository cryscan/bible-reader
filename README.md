# 圣经阅读 · 原文与导读

一款移动端优先的圣经阅读 Web 应用，打开即可阅读经文原文，每章开头附有写作背景，点击「导读」可查看该章的概括、核心主旨与关键意象，方便在手机上随时阅读与理解。

## 功能

- **书卷浏览**：按旧约/新约筛选，每卷展示作者、成书年代与写作背景
- **章节目录**：以网格形式列出章节，预览章节主题
- **章节阅读**：
  - 章节开头展示「写作背景」（可折叠）
  - 经文原文采用和合本风格，带章节号
  - 点击「导读」按钮查看本章概括、主旨、意象
- **导读弹层**：从底部滑出的抽屉，集中展示概括、核心主旨、关键意象、写作背景
- **章节切换**：阅读页底部可快速切换上一章/下一章
- **移动端优化**：羊皮纸配色、衬线字体、触摸友好、响应式布局

## 书签与阅读进度

应用内置两层阅读位置记忆，无需登录或后端：

- **同设备记忆**：每次打开章节会自动写入浏览器 `localStorage`（键 `bible-last-read`）。关闭网页后再次打开，会自动恢复到上次阅读的章节。
- **URL 书签（跨设备）**：当前阅读位置会同步编码到地址栏的 URL hash 中，格式如下：
  - `#/` —— 书单首页
  - `#/genesis` —— 某卷的章节列表
  - `#/genesis/3` —— 某卷第 3 章

### 常见用法

- **收藏 / 分享**：复制地址栏中带 `#/书卷/章` 的链接，发给他人或在其他设备打开，即可直达对应章节。
- **跨设备同步**：将带 hash 的链接加入浏览器书签。在 Chrome / Edge 等登录同一账号的浏览器中，书签本身会随账号同步，从而实现跨设备跳转到同一章节。
- **浏览器前进 / 后退**：阅读过程中使用浏览器的前进、后退按钮，页面会随之在书单、章节列表、阅读页之间切换。

> 说明：`localStorage` 仅保存在本机本浏览器，不会被浏览器账号同步；真正的"云端自动同步"需要后端服务与用户系统，本应用未包含。

## 技术栈

- React 18 + Vite
- Tailwind CSS（羊皮纸主题配色）
- 原生 JavaScript（无额外 UI 库）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（手机同局域网可访问）
npm run dev
```

开发服务器启动后，终端会显示局域网地址（如 `http://192.168.x.x:5173`），用手机浏览器打开即可在手机上阅读。

## 构建部署

```bash
npm run build      # 生成 dist/ 静态文件
npm run preview    # 本地预览构建结果
```

构建产物为纯静态文件，可部署到任意静态托管服务（如 GitHub Pages、Vercel、Netlify 等）。

## 扩展内容

所有经卷与章节内容位于 `src/data/bibleData.js`，按如下结构添加新内容即可：

```js
{
  id: 'romans',
  name: '罗马书',
  nameEn: 'Romans',
  testament: 'new',          // 'old' | 'new'
  category: '保罗书信',
  author: '保罗',
  date: '约公元57年',
  background: '本卷写作背景……', // 整卷背景
  chapters: [
    {
      number: 1,
      title: '章节标题',
      background: '本章写作背景……',
      summary: '本章概括……',
      theme: '本章主旨……',
      imagery: ['意象1', '意象2'],
      verses: [
        { number: 1, text: '经文第一节……' },
        // ...
      ],
    },
  ],
}
```

当前已收录示例经卷：创世记（1–3 章）、诗篇（第 1、23 篇）、约翰福音（1、3 章）。
